Step 1: Admin
Admin generates invite link with trial duration or no expiry. Sets primary + backup model. Sends link to user.
Step 2: User Clicks Link
WhatsApp opens. User names their agent → Done. 2 messages, 30 seconds. Model is pre-configured by admin.
Step 3: Agent is Live
User starts chatting. Agent uses admin-set primary model. Backup kicks in automatically if primary fails. Trial counts down.
⚙️ Behind the Scenes
When admin generates a link:
• Creates a Hermes profile in `~/.hermes/profiles/invite-abc123/`
• Stores link ID, trial expiry, and plan in the user database
• Profile is inactive until first WhatsApp message
When user clicks the link:
• WhatsApp Business API receives the incoming message
• Gateway checks: is this phone number known? → No
• Gateway matches the invite link → activates the pre-created profile
• Links the phone number to the profile permanently
• Triggers the 2-message conversational onboarding
Model routing:
• Every message → try Primary model
• If 429/503/timeout → auto-switch to Backup model
• Admin can override per user (set a different primary)
• No user-visible model selection at any point
Trial & billing:
• Trial start = first WhatsApp message
• On expiry day: agent sends payment link
• If "no expiry" link: user never pays (special users)
• Admin can extend trial or convert to no-expiry from dashboard
